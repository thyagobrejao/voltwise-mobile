# VoltWise Mobile

Mobile application for EV drivers.

## 🚗 Features (planned)

- Find nearby chargers
- Start/stop charging sessions
- Monitor charging status
- Payment integration
- History

## 🛠️ Tech Stack

- Flutter

## 🔗 Backend

- voltwise-cloud API

## 🚀 Goal

Provide a seamless charging experience for EV users.
